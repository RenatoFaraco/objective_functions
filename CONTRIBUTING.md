## 📜 Código de Conduta
Ao participar deste projeto, você concorda em manter um ambiente respeitoso, inclusivo e livre de assédio para todos os membros da comunidade.

## 🚀 Como posso contribuir?

### Reportando Bugs
Encontrou um erro? Abra uma **Issue** no GitHub seguindo estas orientações:
1. Verifique se o bug já não foi reportado.
2. Use um título claro e descritivo.
3. Descreva os passos para reproduzir o erro.
4. Se possível, inclua prints ou logs de erro.

### Sugerindo Melhorias
Ideias são sempre bem-vindas! Ao sugerir uma nova funcionalidade:
1. Explique por que essa melhoria seria útil.
2. Descreva como você imagina que ela deva funcionar.

### Pull Requests (PRs)
1. Faça um **Fork** do repositório.
2. Crie uma branch para sua modificação (`git checkout -b feature/nova-funcionalidade`).
3. Faça o **Commit** das suas alterações com mensagens claras.
4. Envie para o seu fork (`git push origin feature/nova-funcionalidade`).
5. Abra um **Pull Request** para a branch principal (`main` ou `master`).

## 🛠️ Padrões de Código

Para manter a consistência:
- Siga a indentação padrão do projeto (ex: 2 espaços ou Tab).
- Comente partes complexas do código.
- Se você adicionar uma nova biblioteca, documente o motivo no PR.
